# مراجعة الكود: DeleteDataController.java

## الخطوات

- [x] 1. `delete()` تقرأ مربعات الاختيار (`selectedTargets()`) من خيط العمل الذي يشغّله `MaskerPaneSetting`، لا من خيط JavaFX. تُبنى خطة الحذف (`WipePlan`) على خيط JavaFX قبل بدء المهمة، ويستلمها الخيط جاهزة.
- [x] 2. بعد نجاح الحذف تقول الشاشة «تم الحفظ» (`AllAlerts.alertSave()` في `getData`). الصحيح رسالة حذف تذكر ما مُسح.
- [x] 3. التأكيد هو السؤال العام «هل تريد الحذف؟» (`AllAlerts.confirmDelete()`). المطلوب تأكيد يذكر عدد أنواع البيانات التي ستُمسح نهائياً، وأن نسخة احتياطية تُؤخذ أولاً.
- [x] 4. زر «حذف» وزر «إغلاق» كلاهما أزرق: القاعدة `.dialog-pane .button` تغلب `app-danger-button` و`app-neutral-button`. لذلك لا يتميز الفعل المدمّر، ويبدو زر الإغلاق هو الفعل الأساسي. الحل أنماط محصورة في هذه الشاشة.
- [x] 5. شريط الملخص (`summary-bar`) كحلي بنص داكن من `.dialog-pane .label`، فلا يُقرأ في الثيم الفاتح. وهو سطر واحد ينتهي بنقاط حين تكثر الأسماء. يُستبدل بلوحة شرائح، شريحة لكل ما سيُمسح.
- [x] 6. هدف «الجرد الفعلي» (`STOCK_COUNTS`) ليس في أي قسم داخل `sections()`. لذلك يُلحق بقسم «أخرى»، ويُكتب تحذير في السجل مع كل فتح، ويُقص صفه الخامس أسفل البطاقة. مكانه قسم الأصناف، واختبار يضمن أن لكل هدف قسماً.
- [x] 7. البطاقات في `FlowPane` عرض لفّه 820 وعرض البطاقة 260، فتظهر بطاقتان في الصف ويبقى ثلث النافذة فارغاً، والمحتوى يحتاج تمريراً في 860×658. تُرتَّب الأقسام الأربعة في أربعة أعمدة متساوية بلا تمرير.
- [x] 8. نصوص عربية ثابتة في Java: عناوين الأقسام، الملخص، بادئة التلميح، اسم العملية على شاشة الانتظار. وفي FXML: العنوان والوصف والتحذير. لذلك تظهر الواجهة الإنجليزية بالعربية. تُنقل كلها إلى مفاتيح في الملفات الثلاثة.
- [x] 9. قواعد الاختيار (التحديد المتسلسل، وإلغاء ما يعتمد عليه، والإغلاق تحت `requires`) مكتوبة في الشاشة مع علم `cascading`، فلا يمكن اختبارها. تُنقل إلى `features/wipe/WipeSelection` باختبارات، وتصبح المربعات مرآة للاختيار.
- [x] 10. زر «تحديد الكل» لا يتبع المربعات: بعد «تحديد الكل» ثم إلغاء مربع واحد يبقى الزر يقول «إلغاء تحديد الكل». تُشتق حالته من الاختيار.
- [x] 11. الأيقونات صور PNG من `Image_Setting`: تفتح `InputStream` لكل حقل ولا يمكن تلوينها بالثيم. تُستبدل بـ `AppIcon` (Ikonli) حسب §5.
- [x] 12. إطار FXML من 93 سطراً بنصوص ثابتة وبلا `ResourceBundle`. تُبنى الشاشة في الكود، ويُحذف `delete-data.fxml` و`@FxmlPath`.
- [x] 13. مفتاح Escape لا يغلق النافذة، لأن النافذة بلا زر إلغاء من نوع `ButtonType`. يُضاف Escape للإغلاق.
- [x] 14. `delete()` يكتب `com.hamza.account.features.backup.BackupKind` بالاسم الكامل داخل السطر. يُستورد بدلاً من ذلك.
- [x] 15. عنوان النافذة مبني بالتجميع `WORD_DELETE + " " + DATA`، والترتيب يختلف بين اللغات. يصبح مفتاحاً واحداً.
