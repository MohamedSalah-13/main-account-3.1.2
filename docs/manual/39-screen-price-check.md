شاشة يقف أمامها العميل بنفسه: يمرّر الصنف على القارئ فيرى اسمه وسعره، بخط كبير.

![إعداد شاشة الاستعلام قبل فتحها](price-check)

## الإعداد أولًا

قبل أن تفتح الشاشة يسألك البرنامج عن طريقة عرضها:

| المخزن | أي مخزن يُقرأ منه الرصيد |
| سعر البيع المعروض | أي الأسعار الثلاثة يراه العميل |
| إظهار الرصيد المتاح | |
| إظهار صورة الصنف | |
| إظهار تاريخ الصلاحية | |

ثم **موافق**، فتملأ الشاشة الجهاز.

## الخروج منها

`Ctrl+Shift+Q` ثم كلمة مرور المستخدم الحالي. وهذا مقصود: الشاشة تُترك أمام العملاء، فالخروج منها
لا يكون بضغطة عابرة.

## ما لا تفعله

هي **تقرأ ولا تكتب**: لا تبيع، ولا تعدّل سعرًا، ولا تُظهر تكلفة.

> ملاحظة: السعر المعروض هو الذي اخترته في الإعداد، لا سعر شريحة عميل بعينه - لا يعرف الجهاز من
> الواقف أمامه.

> نصيحة: يمكن تخصيص حساب مستخدم يفتح على هذه الشاشة وحدها عند تسجيل الدخول - الخانة موجودة في
> شاشة إضافة مستخدم - فلا تظهر بقية البرنامج على جهاز في متناول العملاء.
