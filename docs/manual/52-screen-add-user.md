حساب يدخل به شخص إلى البرنامج. وهو غير بطاقة الموظف: الموظف من تدفع له، والمستخدم من يدخل.

![شاشة إضافة مستخدم](add-user)

| اسم المستخدم | لا يتكرر، ولا يُعاد استعماله بعد ذلك أبدًا |
| كلمة المرور | تُخزَّن مشفَّرة ولا يستطيع أحد قراءتها، ولا أنت |
| الدور | مجموعة الصلاحيات التي يبدأ بها |
| نشط | |

> تحذير: **لكل شخص حساب باسمه.** الحساب المشترك يعني أن سجل المراجعة يقول «من فعل هذا؟ admin» عن
> كل شيء، وهو لا يقول شيئًا.

> ملاحظة: لا تعطِ حساب العمل اليومي دورًا يفتح كل شيء. أصغر دور يكفي عمله هو الصحيح، ويمكن زيادته
> في أي وقت.
